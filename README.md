## Topik
Exploratory Data Analysis (EDA) mengenai tren ancaman siber, distribusi korban, kerugian finansial, dan waktu mitigasi serangan.

## Sumber Dataset
* **Nama Dataset:** Global Cybersecurity Threats (2015-2024)
* **Sumber:** Kaggle
* **Link:** [https://www.kaggle.com/datasets/atharvasoundankar/global-cybersecurity-threats-2015-2024]
* **Lisensi:** [CC0: Public Domain]

## 3 Temuan Utama
1. Distribusi jumlah pengguna terdampak tersebar secara seragam dari mendekati 0 hingga 1.000.000 korban tanpa adanya anomali (*outlier*).
2. Serangan *Ransomware* memiliki waktu pemulihan terlama dengan median 38 jam, sementara *DDoS* dan *Phishing* merupakan yang tercepat dengan median 35 jam.
3. Tren kerugian finansial cenderung stabil di angka 260–320 juta Dolar per tahun, dan tidak ditemukan korelasi linier antara tingginya jumlah korban dengan besaran kerugian finansial.
